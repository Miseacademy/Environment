# Welcome to Misecademy Agentic-AI Lab Environment

This repository is designed for **practice exercises** in your DevOps course. You can open this repository in **GitHub Codespaces** and work on it freely.

---

## 1️⃣ Open the GitHub Codespaces

Click the **Code and open Codespaces**

> Each student gets their **own Codespace instance**, so your changes will not affect other students.

**Usage Limits:**

1. Maximum **60 hours per month** per student.  
2. Generative AI : Maximum **2000 prompts per month**.  
3. Agentic AI    : Maximum **50 prompts per month**.
